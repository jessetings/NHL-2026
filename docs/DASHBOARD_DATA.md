# Dashboard data contract (schema v1)

Generated by `python src/dashboard/export.py`. It also runs from `nightly.sh` and `scripts/daily_refresh.sh`. Output goes to `dashboard/data/`.

| File | Contents |
|---|---|
| `manifest.json` | `schema`, `generated_at`, `slates` (dates), `files` |
| `slates/<date>.json` | `games[]` (game, start, state, scores), `first_goal{}`, `picks[]`, `tickets[]`, `summary{source: n, settled, won, staked, pnl, roi, avg_clv, n_clv}`, `final` |
| `performance.json` | `by_source_daily[]` (daily and cumulative paper P&L/CLV per source), `ledger[]` (real bets), `bankroll_curve[]` |
| `calibration.json` | Reliability `bins[]` (p_mean vs hit vs implied) over settled single picks |
| `research.json` | `open_edge`, `props_v2_eval`, `sim_tails` tables, plus `headline` (live rule and its backtest numbers) |

**Pick fields:** `source` (pyramid / early), `tier`, `game`, `player`, `team`, `role`, `market` (SOG/G/A/PTS), `side`, `line`, `book`, `odds`, `p`, `p_model`, `p_market`, `implied`, `stake` (fraction of bankroll as published), `actual`, `result` (open / won / lost / push / void), `pnl` (bankroll fraction), `close_odds`, `clv`.

`clv` is the implied probability at close minus the implied probability at our price. It is positive when the market moved our way.

**Ticket fields:** `tier` (small / medium / moonshot), `legs[]` (each leg's player, market, side, line, book, odds, result), `payout_x`, `p`, `ev`, `stake`, `result`, `pnl`.

**Sources:**
- Card CSVs: `cards/<d>/pyramid_placed.csv`, `pyramid_tickets.csv`, `early_bets.csv`. Slates older than `early_bets.csv` are reconstructed from `early_all.csv` using the published rule.
- `ledger/bets.csv`: bets actually placed, entered by hand. See `ledger/README.md`.

**Results:** NHL boxscores, cached to `cards/<d>/results.parquet` once every game is final. Same-name players are separated by game and F/D. Anything ambiguous is graded `void`.
